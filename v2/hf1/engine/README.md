## 1. 一句话逻辑

与 v2.1 共用同一市场闸门和同一 120 只核心池，在同一天叠加三层入场：A 深回撤（就是 v2.1 的入场）、B 极端超卖收阳、C 5 日急跌收阳。用更多机会换更高频率，但 A 层与 v2.1 同源，不能当作独立分散。

## 2. 精确规则

### 2.1 市场闸门

- 指数 > MA50，且 5 日平滑宽度 ≥ 45%（与 v2.1 相同）。
- 闸门关闭时三层全部停止开新仓；已有仓位按各自规则管理。

### 2.2 三层入场（收盘判定，下一根日线开盘成交）

| 层 | 条件 | 过滤 | 出场 |
|---|---|---|---|
| A 深回撤 | 收盘 > MA100；MA100 20 日斜率 ≥ 0；20 日偏离 ≤ −4%；RSI2 ≤ 25 | 价格 ≥ 5；dv20 ≥ 30M；ATR% ≤ 4.5%；3 日收益 ≤ 9.9% | 止损 2.5 ATR；止盈 2.0 ATR；最多 10 根 |
| B 极端超卖 | 同上趋势；偏离 ≤ −2%；RSI2 ≤ 15；收阳 | 价格 ≥ 5；dv20 ≥ 20M；ATR% ≤ 6% | 止损 2.0 ATR；止盈 1.5 ATR；最多 7 根 |
| C 5 日急跌 | 同上趋势；偏离 ≤ −2%；RSI2 ≤ 25；收阳；5 日收益 ≤ −5% | 价格 ≥ 5；dv20 ≥ 20M；ATR% ≤ 5% | 止损 2.0 ATR；止盈 1.5 ATR；最多 7 根 |

- 同日多层命中时按 A/B/C 去重，保留优先级更高的一层。
- 所有条件只用收盘及以前的数据；下一根日线开盘入场。

### 2.3 仓位与成本

- 5x 逐仓；单笔保证金 = 权益 × 2.5%（名义 = 权益 × 12.5%）。
- 最多 20 个同时持仓；总毛敞口 ≤ 2.5 × 权益。
- 成本与 v2.1 相同：手续费 + 滑点 0.20% 往返，资金费 0.03%/日。
- 5x 爆仓距离约 19%；单笔止损占权益典型 0.6%–1.5%。

## 4. 文件与运行

| 文件 | 作用 |
|---|---|
| `hf7.py` | 分层定义、闸门、评估函数（B/C 层规则） |
| `hf_board.py` | 全量回测 + 当日候选/候补 + 写出 `hf1.json` |
| `hf_page.py` | 读取 `hf1.json` / `sweep7.json`，渲染 `hf1.html` |
| `sweep7.json` | 页面使用的参数扫描快照 |
| `../../hf1/hf1.json` | 已发布页面数据 |
| `../../hf1/index.html` | 已发布页面 |

从仓库根目录运行（本地重建）：

```bash
python v2/hf1/engine/hf_board.py   # 写 v2/hf1/engine/hf1.json
python v2/hf1/engine/hf_page.py    # 写 v2/hf1/engine/hf1.html
```

发布（需明确批准）：把 `v2/hf1/engine/hf1.json` 复制到 `v2/hf1/hf1.json`，把 `v2/hf1/engine/hf1.html` 复制到 `v2/hf1/index.html`。

说明：`hf_page.py` 需要同目录的 `sweep7.json`（已入库）。缓存默认从仓库根目录的 `cache_fresh/` 读取；缓存放在别处时，在命令前加 `V2_CACHE=/绝对路径`。

## 5. 执行清单

1. 先看闸门；关闭就空仓，不做例外。
2. 页面候选表按层标注；A 层与 v2.1 重复，若 v2.1 已持有同一标的，不要重复开仓。
3. 按页面给的 E/止损/止盈/数量/保证金下单；E 可用次日开盘修正。
4. 5x 逐仓、单笔 2.5% 权益、最多 20 仓、总毛 ≤2.5x。
5. 记录实际成交与滑点；与回测偏差大时先查执行。

## 6. 已知限制

- 与 v2.1 同池同闸门，相关性极高；HF-1 的机会数放大不等于风险分散。
- 全样本含 2025 年回填段；2026 段 48 笔，样本仍不算厚。
- 只做多；闸门长期关闭时会长时间无单。
- 日内顺序、盘口深度、真实滑点和资金费变化未完全建模。
