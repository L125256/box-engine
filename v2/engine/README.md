## 1. 一句话逻辑

只在“指数在 MA50 上方、且市场宽度足够”时，买入上升趋势里刚出现短期超卖的核心股票；用 2.5 ATR 止损、2.0 ATR 止盈、10 根日线时间退出，5x 逐仓、单笔 4% 权益、最多 12 仓。

## 2. 精确规则

### 2.1 市场闸门（v2.1 与 v2 的唯一区别）

- 等权指数：池内标的日收益等权平均后链接成指数（`v2_lib.build_regime`）。
- 基础闸门：指数收盘 > 指数 MA50。
- 宽度：池内收盘站上自身 MA50 的标的占比；取 5 日平滑值。
- **v2.1 执行闸门 = 指数 > MA50 且 5 日平滑宽度 ≥ 45%。**
- v2 对照 = 只看指数 > MA50。页面同时展示两者，下单只用 v2.1。

### 2.2 入场（收盘判定，下一根日线开盘成交）

全部满足：

- 收盘 > MA100，且 MA100 的 20 日斜率 ≥ 0（`slope100 >= 0`）。
- 20 日偏离 `close / MA20 - 1 ≤ -4%`。
- RSI2 ≤ 25。
- 3 日收益 ≤ 9.9%（防止追高）。
- ATR% ≤ 4.5%。
- 收盘价 ≥ 5；20 日成交额中位数 ≥ 3000 万美元。
- 至少 210 根历史；数据非跳变、非回填段之外的真实 bar。
- 同日多信号按 RSI2 从低到高排序；A 层优先。

### 2.3 出场

- 止损：入场价 − 2.5 × ATR。
- 止盈：入场价 + 2.0 × ATR。
- 时间退出：持有 10 根日线，按收盘平仓。
- 跳空：开盘已低于止损按开盘价成交；开盘已高于止盈按开盘价成交。
- 同一根 bar 内止损与止盈都触及时，回测按**先止损**处理（保守）。

### 2.4 仓位

- 5x 逐仓；单笔保证金 = 当前权益 × 4%（名义 = 权益 × 20%）。
- 最多 12 个同时持仓；总毛敞口 ≤ 2.5 × 权益。
- 止损距离占权益约 `2.5 × ATR% × 5 × 4%`，典型 1%–2%；单笔爆仓距离约 19%，止损通常先触发。

### 2.5 成本

- 手续费 0.05% + 滑点 0.05% 每边，往返 0.20%。
- 资金费 0.03%/日，按名义计。
- MMR 1%，爆仓手续费 0.6% 名义。

## 4. 文件与运行

| 文件 | 作用 |
|---|---|
| `v2_lib.py` | 数据加载、指标、信号、组合模拟、统计 |
| `v2_final.py` | 冻结的 A/B 规则、窗口/滚动工具 |
| `v2_diag.py` | 全量回测，输出 `v2_page.json` |
| `v2_addendum.py` | 宽度确认、基准对照、资金费、审计数据，合并进页面数据 |
| `v2_bases.py` | 非 MA50 闸门基准对照，写出 `v2_bases.json` |
| `v2_live_board.py` | 当日看板、候补、健康度 |
| `v2_update.py` | 一键流水线：刷新 → 回测 → 基准 → 合并 → 出页面 |
| `v2_page.py` / `v2_template.html` | 页面渲染 |
| `refresh_fresh.py` | 刷新 144 只日线到缓存 |
| `VERSION.json` | 冻结配置快照 |
| `engine_snapshot/cleaned_pool.json` | 144 只定版池 |

从仓库根目录运行：

```bash
# 刷新数据（约 2 分钟；失败会非零退出）
python v2/engine/refresh_fresh.py cache_fresh 6

# 用缓存本地重建（写入 dist/，不覆盖线上 v2/index.html）
python v2/engine/v2_update.py --skip-refresh --cache cache_fresh --outdir dist
```

核对 `dist/index.html` 与 `dist/build_report.json` 后，**经明确批准**再复制到 `v2/index.html` / `v2/build_report.json`。不要把 `--outdir` 直接设成 `v2`。

只核对数据、不写页面：

```bash
python - <<'PY'
import os, sys
sys.path.insert(0, 'v2/engine')
os.environ['V2_CACHE'] = os.path.abspath('cache_fresh')
import v2_lib as L
from v2_final import A_RULES, dedupe
raw, cal, g = L.load_all(False, False)
A = L.align(raw, cal, g); F = L.features(A); RG = L.build_regime(A, cal)
BR, _ = L.breadth(A, F, cal)
BR0 = __import__('numpy').where(__import__('numpy').isnan(BR), 0.0, BR)
RGx = dict(RG); RGx['gate'] = RG['gate'] & (L._roll(BR0, 5) >= 0.45)
sig = dedupe(L.make_signals(A, F, RGx, BR, dict(A_RULES)))
sim = L.simulate(A, F, RGx, sig, dict(lev=5, margin_pct=0.04, max_pos=12, gross_cap=2.5))
print(L.stats(sim, 200, len(cal) - 1))
PY
```

## 5. 执行清单（人工下单）

1. 确认数据日期是最近一个已收全的交易日；尾根未收全不用。
2. 确认 v2.1 闸门打开（页面显示“闸门开”）；关闭就空仓，不做例外。
3. 页面候选表给出 E、止损、止盈、数量、保证金、到期日；E 默认收盘价，实盘以次日开盘为准，可改 E 后自动重算。
4. 5x 逐仓；单笔保证金 4% 权益；最多 12 仓；总毛 ≤2.5x。
5. 止损/止盈挂交易所条件单；到期日按 10 根日线，不是 10 个美股交易日。
6. 成交后记录实际 E、滑点、资金费；与回测偏差大时先查执行，不要先改规则。

## 6. 已知限制

- 2026 真实段样本薄；全样本含 2025 年回填段。
- 只做多；市场整体下跌时闸门会长期关闭，空仓期可能很长。
- 回测按日线 OHLC 近似，无法刻画盘中顺序、盘口深度和真实滑点。
- 资金费按固定 0.03%/日，实际会随市场变化。
- 同池同闸门的 HF-1 与本系统高度相关，不能当作独立风险分散。
