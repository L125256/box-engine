1. fd 信号怎么读

fd 是什么：fd = 回归买入信号（箱底回踩）。三个条件同时满足才打 fd 标：

  1. 牛市闸开放：池内 144 只票等权均价（idx）在 50 日均线上方（页面温度计 🟩）；
  2. 票在箱体内横盘收窄锁定：连续 m=2 根 K 线收进 N=20 根窗口、宽度 < k=6×ATR 的箱体；
  3. 收盘回踩箱底容忍带：收盘价落进「箱底 + e=0.2×箱高」的容忍带。

读法：「值得加入自选观察」——不是买入指令。触发判定按收盘价，盘中触摸不算数；看到 ⚡接近 fd 回踩观察区的标注，含义是「收盘落进观察带了，可以留意」，参考观察，非买入指令。牛闸关闭（🟥）时 fd 不触发，锁定再多也只是干等。

双轮读法：本页数据每天生成两轮——09:00 轮=判定级（当日收盘判定基准，徽标绿色）；21:00 轮=盘中快照·不可操作（盘中快照仅供参考，徽标黄色）。fd 信号一律以收盘判定为准：21:00 轮上看到的 ⚠️ 状态只当"路上瞄一眼"，不可当当日收盘结论操作。

3. 双参数组是什么（本页专属 FAQ）

为什么页面上有两个参数组？页面对同一批数据跑了两套参数：

参数组参数身份
冻结基线（主区默认）N=20 / k=6.0 / m=2 / e=0.2v1.0 验收时冻结的「官方参数」，本页主区唯一默认
Top1（底部折叠区）N=15 / k=7.5 / m=2 / e=0.3回测统计略优的研究候选（pf 1.194 vs 1.129），从未实盘授权

要点：两个都是研究参数组，都不是实盘指令。切换视角只是换一个「平行世界」看同一批票——持仓、触发区全都会变，所以 Top1 收在底部折叠区并标注「候选研究组·非实盘」，主区永远锁冻结基线。没有哪个参数组是"该跟的"。

4. 与 F1 的关系声明

  • 两套独立引擎：箱体引擎（eng_final.py）与 F1 引擎（f1_signal.py）独立运行、独立参数、互不共用持仓；
  • F1 页出指令，本页出观察：F1 页（/f1/）有仓位档（2.5%）、熔断、调仓日历——那些是操作体系；本页只有 fd 参考信号与温度计，没有任何操作指令；
  • 同一只票两边信号不同属正常，互不保证、互不背书。

双闸分离（2026-10-21 终裁）：F1 页的市场总开关是 F1 闸（idx｜MA50，收盘纪律：只吃已落定日 K，判定轮算一次冻结）；本页温度计是 箱体闸（盘中实时）。两闸各自独立计算、互不影响、互不背书——盘中看箱体闸、收盘看 F1 闸。箱体闸入口带数据卫生三道门：①日期格式归一化（time 归一 date-only）；②混格式拒载（同一票内原始时间格式混写→整批拒载，宁缺勿错）；③覆盖率门 ≥80%（当日 bar 覆盖率不足→闸值作废沿用上一收盘值并标注）。两页闸区均按口径四要素标注：闸名｜池口径｜数据日期｜样本数——看任何闸值先读这四项。

与 F1 分域增强的关系：箱体（本页）提供的是观察参考（fd 观察区、温度计）。其中 fd 出场结构已被选为 F1 页『分域增强』实验格 S5，按重重检测四层全过当日满额部署（F1 页独立小仓）——箱体页本身不部署任何仓位，两页互不背书；看到 fd 观察区信号≠可买，操作依据唯一=F1。

5. bk 为什么被折叠归档

bk = 突破买入信号（收盘上穿箱顶 + 0.25×ATR）。经穷举研究已判死归档：页面上所有 bk 内容都收进底部折叠区、整体置灰，钉死标注「⛔ 已穷举归档 · 非信号 · 仅存档对照」。它不参与接近触发提示、不参与任何计数强调，数据在 JSON 里原样保留只为历史账对照。看到 bk 字样 = 存档，不是信号。

6. 术语小词典（页面黑话翻译）

黑话白话
fd / bkfd=回归买入（牛市闸开放 + 收盘回踩箱底容忍带），有参考价值；bk=突破买入（收盘上穿箱顶+B×ATR），已穷举判死归档、非信号
