## 1. 一句话逻辑

不设全市场闸门，只看个股自己的趋势和强度：站上 MA50 且 MA50 > MA100、两条均线都向上、20 日收益为正，然后在回踩 MA20（20 日偏离 ≤ −2%）且 RSI2 ≤ 40 时买入；+0.8 ATR 止盈、−1.5 ATR 止损、最多 5 根日线。

它和 FD-1 的区别：FD-1 只要求 MA100 向上、踩得更深（−5%）且 RSI2 更低（30）；P6 要求 MA50 > MA100、20 日为正、踩得更浅（−2%），所以信号更多、单笔优势更弱。**P6 目前只是研究项，不能因为 2026 段好看就上线。**

## 2. 精确规则

### 2.1 入场（收盘判定，下一根日线开盘成交）

单只个股全部满足：

- 收盘 > MA50 > MA100。
- MA50 的 10 日斜率 ≥ 0；MA100 的 20 日斜率 ≥ 0。
- 20 日收益 > 0（绝对强度；不要求跑赢指数）。
- 20 日偏离 `close / MA20 - 1 ≤ -2%`。
- RSI2 ≤ 40。
- 收盘价 ≥ 5；20 日成交额中位数 ≥ 3000 万美元；ATR% ≤ 6%。
- 只做个股：剔除 ETF 与杠杆 ETF。
- 至少 220 根历史；非数据跳变、非回填段之外的真实 bar。
- **无市场闸门**：指数在 MA50 上下都不影响入场。

### 2.2 出场

- 止盈：入场价 + 0.8 × ATR。
- 止损：入场价 − 1.5 × ATR。
- 时间退出：最多 5 根日线，按收盘平仓。
- 跳空：开盘已低于止损按开盘价成交；开盘已高于止盈按开盘价成交。
- 同一根 bar 内止损与止盈都触及时，回测按**先止损**处理（保守）。

### 2.3 组合口径

- 5x 逐仓；单笔保证金 = 权益 × 3%（名义 = 权益 × 15%）。
- 最多 16 个同时持仓；总毛敞口 ≤ 2.5 × 权益；同日最多 5 个新仓（`capday=5`）。
- 成本：手续费 + 滑点 0.20% 往返；资金费 0.03%/日；5x 爆仓距离约 19%。

## 5. 文件与运行

| 文件 | 作用 |
|---|---|
| `rs_lab.py` | P1–P10/B/R 变体、P6 汇总、仓位敏感性、按市场状态拆分 |
| `rs_scan.py` | 当前 P6 候选 + 强势观察 |
| `rs_hold.py` | 探索性“沿 MA10 持有”版本，不是 P6 生产规则 |
| `p6_results.json` | 2026-10-31 的 `rs_lab.py` 结果快照（UTF-8） |

从仓库根目录运行：

```bash
# 当前候选（快）
python systems/p6/rs_scan.py

# 全量变体（较慢；会重写 systems/p6/rs_lab.json）
python systems/p6/rs_lab.py

# 探索性趋势持有版本（只研究）
python systems/p6/rs_hold.py
```

数据默认读仓库根目录的 `cache_fresh/`；也可用绝对路径：

```bash
V2_CACHE=/path/to/cache_fresh python systems/p6/rs_scan.py
```

## 6. 已知限制

- 全样本 PF 1.10、2025 段 PF 0.93，不足以支持实盘；2026 段好看但只有 51 笔。
- 无市场闸门，系统性下跌时会连续开仓/止损；不能因为“个股趋势还在”就忽视宏观风险。
- 与 FD-1、点火、v2.1 都是做多美股代币，极端行情相关性趋近 1。
- 日线 OHLC 无法刻画盘中顺序；跳空可能穿止损。
- 5 根时间退出约 5 个自然日，不是 5 个美股交易日。
