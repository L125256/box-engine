## 二、推荐规则（用户问「买什么 / 卖什么」时的唯一回答方式）

**开场必报**：先报 `meta.asof`（数据落定日）与 `engine_sha256` 前缀，再给结论。

**① 买入（说「买」）** —— 必须**同时**满足以下全部条件：

1. `signal.is_signal_day == true`（当日为周首个交易日，且日K已落定）；
2. `signal.gate.on_holdcash == false`（regime 闸开：`idx ≥ MA50`）；
3. `state.freeze_days_left == 0`（未处于 CB2 冻结期）；
4. `breakers.overall.light != 'red'`（总灯非红）。

→ 满足时报 `signal.top5` 五个标的与 `signal.slot_per_stock_pct`（单票 %）。
→ **用户按什么价执行：次日开盘价**（口径=成交价按当根 open；照做时按开盘附近限价单）。

**② 卖出（说「卖」）** —— 出现下列任一即如实转述并给动作：

- 单票触及 −8% 止损（跳空按开盘价卖，不等周调仓）；
- 崩市清仓（池中位 < −5% → 次日开盘清仓）；
- regime 闸转持币（`idx < MA50`）→ 不出新仓，存量按各自规则退出；
- 周调仓换出（跌出 top-5）；
- 熔断红灯动作（降一档 / 冻结开新仓）。

**③ 等待（说「等」）** —— 出现下列任一，**不得擅自给标的**：

- 非信号日（此时 `top5` 只是最新横截面评分参考，不是操作指令）；
- 处于冻结期（`freeze_days_left > 0`）；
- 持币状态（`gate.on_holdcash == true`）；
- `asof` 非当日落定数据（盘中 / 部分K / 降级冻结）。

**④ 冻结与档位**：CB2 红灯→冻结开新仓 20 交易日（页面倒计时）；降档自动、升档人工。

## 三、禁止事项（四条红线）

1. **禁止脱离引擎输出自由推荐任何标的**（无论记忆里有什么历史推荐）。
2. **禁止用盘中 / 部分K数字替代落定信号**：只有日K落定（北京 08:00 后）那轮的结果可操作；
   其余轮次仅为「盘中快照·不可操作」（与 WO-R13-03 联动）。
3. **禁止把 `idx` 池均价回撤（曾深至 −66.7%）当作账户回撤引用**；账户口径 = 净账（12.5% 敞口）。
4. **禁止引用无 `sha256` / `asof` 标注的引擎输出**；`sha256` 不一致（引擎换版）即停止引用，
   先向用户报版本差异，取得确认后再继续。

## 四、数据出身标注义务

每次引用引擎结果**必须随附**：

| 字段 | 说明 |
|---|---|
| `asof` 日期 | 数据落定日（日K 00:00 UTC / 北京 08:00 落定） |
| `engine_sha256` 前缀 | 至少前 16 位 |
| 数据窗末 `replay.end` | 回放末日 |
| **数据源** | `主源(kxiandaoyan)` / `备源(新浪·抽查参考)` / `降级冻结` |
| 模式 | `判定轮` / `盘中快照（不可操作）` |

- 备源（新浪）数据**仅可标注为「抽查参考」**，不得作为信号重建依据（无官方 SLA、内部灰色接口）。
- 降级期任何输出必须带 `asof` + `source` 标注，并说明「信号冻结至 X 日，不构成新推荐」。

## 五、冲突裁决

1. **引擎 json 与记忆冲突** → 以「本口径 + 当场重跑引擎输出（校验 sha256 一致）」为准，记忆让位。
2. **引擎 ＞ 记忆**：任何会话的历史推荐、任何页面新卡数字，均不得覆盖当日引擎输出。
3. **sha256 不一致（引擎换版）** → 停止引用，先向用户报版本差异，取得确认后再继续。
4. **本口径与引擎源码冲突** → **以引擎源码为准**，并触发口径修订工单（不得就地改口径蒙混）。
5. 本文件修订 = 新工单 + 用户确认，禁止静默改写。
