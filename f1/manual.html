📊 运行状态📖 使用说明
本手册与引擎 f1_signal.py（v1，seed=42）实际行为逐条核对 · 与引擎不一致处以引擎为准 · 模拟数据，请勿仅依赖本系统决策
一句话：一台每周从 144 只票里打分选出 5 只的「自动选票机」，你只负责照着它给的清单下单。

1. 这个系统怎么赚钱

  • 每只票按四个因子打分（均线斜率、量能斜率、离一年高点多近、近一月涨幅），分最高的 5 只等权买入；
  • 每周第一个交易日收盘出一次新榜单，全量重选：掉出榜单的卖掉、新进榜单的买入（周调仓，没有「跌出前 15 才换」的缓冲，掉出即卖）；
  • 大盘环境不好时（池均价跌破 50 日均线，原始术语 regime 闸）整个闸门关闭，空仓躲跌。

2. 怎么买

你在哪看：页面第一屏「当前状态」大字条 + 「现在该做什么」区域。

什么条件才显示买入：同时满足以下四条，top-5 卡片上才出现红色 [目标仓 2.5%]：

  1. 市场总开关开放（🟩，池均价在 50 日均线上方）；
  2. 当天没触发崩市（页面「⚠️ 崩市检测」行未出现）；
  3. 熔断总灯不是「动作中」（没有降档/冻结触发）；
  4. 不在冻结期（健康灯区「冻结剩余 N 天」倒计时已结束）。

闸门关闭时 top-5 仍会显示分数（仅作参考排名，当前不建仓），每张卡标绿色 [闸门关闭·不开仓] —— 看到这个标记，一股都不买。名单只是评分参考，开关恢复后下一信号日按此优先。

按什么价下单：信号是每周第一个交易日收盘后生成的（按数据日历算「周首个交易日」，含周末的 7×24 市场，多为周一），成交在次日开盘：

  • 信号日收盘后（页面更新后）看到新榜单 → 次日开盘下单，按开盘价附近委托即可；
  • 其他日子页面显示的是「最新评分参考」，不动手，等下一次周信号日。

单票多少钱：总资金的 2.5%/票，最多 5 票 = 总敞口上限 12.5%。例：账户 10 万，一票 2500 元。熔断降档后这个数字变小（见第 6 节降档表），以页面顶部「仓位档：第 N 档 · 单票 X%」徽章为准。注意这是名义资金比例，不是收益率，也不建议为此加杠杆。

退出类型触发条件在哪看触发后执行时点口径
止损 −8%持仓票价格从买入价跌 8%自己盯盘（页面监控明细是事后记录，不是实时提醒）发现即卖，手动卖出：能盯盘的触线立即卖；不盯盘的收盘后扫描，最迟次日开盘第一时间卖。跳空低开直接按开盘价卖发现即卖（不等周调仓）

4. 止损是你手动执行的

这套系统的止损不会自动帮你成交。引擎只负责记录与口径：算出止损价（买入价 × 0.92）、在监控区记录。真正按下卖出按钮的是你。

  1. 每笔买入当天，随手记下买入价，算出止损价（×0.92）；
  2. 每天扫一眼持仓，有票逼近/跌破止损价 → 手动下单卖出，别拖、别补仓、别「再等等」；
  3. 跳空低开（开盘价已低于止损价）时按开盘价直接卖——实际亏损会超过 8%（例：2026-09-09 GPRO 实亏 −12.2%）。这是口径内的正常损耗，不要因为「卖低了」而不卖。页面不说「最大亏损 −8%」，因为跳空日可以亏更多。

5. 怎么止盈：这套系统没有固定止盈

盈利的单子没有任何卖出线，退出只有两条路：①换仓（掉出 top-5）；②闸门关闭/崩市清仓。

为什么不止盈：动量策略的利润分布是「肥尾」——大部分票小赚小亏，少数大牛票贡献几乎全部利润。设 +10%/+20% 止盈线等于亲手把肥尾剪掉。赚大钱靠拿得住：赚着的票只要还在榜单里、市场环境还在，就一直拿着。忍住不卖，本身就是策略的一部分。

6. 熔断灯怎么看（策略健康灯）

页面「🚦 策略健康灯」区：四盏小灯 + 一盏总灯。颜色统一：🟢正常 / 🟡预警观察 / 🔴触发动作（红灯=要做一个动作，不是灾难，别全仓逃跑）。

灯什么意思红灯时你要做什么
回撤闸（CB1）近 20 个交易日净账最大回撤（MDD=这 20 天里从最高点算的最大跌幅）。≤−8% 触发；≤−4% 黄灯观察降一档（自动落盘，按下面降档表）
止损闸（CB2）近 60 日止损失血。毛账触发有两条旁路：止损单合计失血 ≤−5pp，或 60 日毛跌 ≤−5%；毛账先报警（黄灯），净账（扣完费的账）也确认才红灯冻结开新仓 20 个交易日（只卖不买，存量按各自规则处理；页面显示剩余天数倒计时，到期自动恢复开新仓）
频次观察（CB3）近 60 日止损次数 ≥ 基准×3（冻结基准 9.07，观察线 27.21 次）只观察，不动作（黄灯而已，不会自动升/降仓）
费用闸（FEE）近 60 日费用（滑点+资金费）折年化拖累 ≥4 个百分点触发；≥2 黄灯降一档（自动落盘）

降档表（单票仓位，只降不升）：2.5% → 1.5% → 1.0% → 0.5%。降档自动写盘，要升回去需人工复核解锁，你无权自己加回。

总灯怎么看：任一红灯 = 执行对应动作（多个红灯取最严：冻结 > 降档 > 观察）；只有黄灯 = 观察不动手；全绿 = 正常运行。总灯下的「建议」文字直接照做即可。

7. 每天 / 每周 / 每月做什么

每天（收盘后 1 分钟 + 次日开盘前后 1 分钟）：

  1. 收盘后页面更新，扫三处：第一屏「当前状态」大字条、健康总灯、⚠️ 崩市检测行；
  2. 有止损触发的持仓 → 按第 3 节口径手动卖出（能盯盘触线即卖，否则最迟次日开盘）；
  3. 其余情况不动。

页面一天会更新好几轮，只有一轮能照着操作：20:30 / 00:30 / 04:30 三轮是盘中快照，只展示持仓浮盈亏、熔断预演、崩市预估，页面会标「盘中快照·不可操作」——看到这个标注，只看不动。只有日K落定后（北京早上 8 点后）那轮的判定结论才算数。

每周（信号日=每周第一个交易日，多为周一，收盘后）：

  1. 看新 top-5 榜单；
  2. 若总开关开放：对比旧持仓 → 次日开盘卖出掉榜的、买入新进的（各按当前档位）；
  3. 若总开关关闭：不开新仓；存量按止损/崩市/换仓规则自然退出。

每月（首个交易日，月报随信号更新）：看「📒 三本账月报」表：

  1. 毛账（不含费的账）/净账（扣完滑点+资金费你实际拿到的）——做决策看净账，看自己实际赚没赚；
  2. 费用账——对照费用闸，费用失控会自动降档；
  3. 跑输躺平(+)/跑赢躺平(−)（原始术语「让渡」=池等权买入持有 − 策略毛账）：正数=这段时间无脑买满一篮子比策略赚得多，是付给择时保护的机会成本；负数=策略跑赢了躺平持有。三个月连着大正 + 无熔断，才轮得到讨论加仓（需人工签批）。

哪天页面出现「降级冻结」：说明数据源出故障了，信号已冻结、不会出新推荐，期间不要按旧榜单操作，等页面恢复；恢复前的备源数字只供抽查核对，不当操作依据。

8. 分域增强插件（F1 之外的实验小菜）

这是什么：F1 主引擎之外，我们另外开了几张很小的『实验菜地』（每块不超过总资金的 0.5%，四块加起来不超过 2%）。它们来自研究挖出的分域信号，正在真金白银的小仓位上接受考验。

怎么看：每张卡片显示：属于哪种行情（域）、现在运行得怎么样（影子计数 n/20）、当前用几折仓位（折扣档位）。折扣越低=证据越弱；显示 ⚠ = 已停用。

能不能买：不需要你操作——小仓自动运行。你若想手动跟，把它当高风险实验仓，金额不超过卡片折算的小仓，且绝不能因此少买或不买 F1 榜单；卡片本身不是买入指令。

和 F1 什么关系：完全独立的两套账。F1 是主菜（12.5% 敞口，熔断灯管着），增强层是小菜（≤2%，自己有折扣机制）。行情变坏时小菜先停，主菜按 F1 自己的规则走。任何冲突听 F1。

9. 术语小词典（页面黑话翻译）

黑话白话
RWR月度滚动重验：衡量策略还够不够格留在组合里的月度体检。滚动 3 个月中位数跌破准入线 60% → 降一档；连续两期不达标 → 冻结+人工复审。加仓的唯一条件是它连续两期 ≥60% 且期间无熔断
V2 口径「可实现出场」的回测算法：成交价按当根开盘价，止损跳空按开盘价、否则按止损价——即模拟你真实下单能拿到的价格，不是理想化收盘价
毛账 / 净账毛账=不算任何费用的账面收益；净账=扣掉滑点和资金费后你实际拿到的收益。做决策看净账
regime（闸）/市场总开关大盘环境开关：池均价在 50 日均线下方=环境差，闸门关闭、空仓观望；收复后重新开闸
idx池内 144 只票当日等权收盘价的平均，自制「池子大盘指数」，用来算总开关和崩市
MA50idx 的 50 日移动平均线。idx 跌破它=闸门拉下
top-5 等权每期只持 5 只票，每只金额一样（单票 2.5% 起步）
四因子合成分均线斜率 / 量能斜率(OBV) / 距一年高点距离 / 一月动量，四项标准化后取平均的相对分（分高=比池里其他票强），极端值截断在 ±3
CB1/CB2/CB3三个熔断器：CB1=回撤闸（短期回撤保险丝）；CB2=止损闸（止损失血保险丝，双账确认）；CB3=频次观察线（只看不动）
pp（百分点）两个百分数之间的差。如「费用年化拖累 ≥4pp 触发降档」=费用一年吃掉 4 个百分点的收益，就降一档
滑点 / 资金费滑点=买卖时成交价不如预期的损耗（按 0.05%/边计）；资金费=持仓期间按日计的持有成本（0.03%/bar）
slot / 档位单票仓位大小。档位表 2.5%→1.5%→1.0%→0.5%，熔断降档用，只降不升
崩市（CRASH）池内单日中位数跌幅 <−5%，判定为系统性崩盘，次日开盘清仓
T+1 执行今天出信号/触发，明天开盘才成交
跳空 / stop_gap开盘价直接低于止损价（中间没有成交机会），只能按开盘价卖，亏损会超过 8%
