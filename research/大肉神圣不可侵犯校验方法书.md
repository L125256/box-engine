## 第一章 定义与实现口径（T1，冻结）

**1.1 大肉事件定义**（决策日 T 锁定，事前可知）：
- `entry_missed`：T 日治理档拦截、base 档入场；
- `entry_deferred`：T 日治理档顺延、T+10 交易日窗内治理档回补入场；
- `exit_deferred`：T 日治理档延迟退出、base 档按原路径退出。
- 事件命中集合在 T 日按 1.3 红线锁定并预登记，**禁止事后回看实现结果再扩集合**。

**1.2 实现口径（永久锁死）**：
- 大肉成本 = 该标的在**反事实档（base，同一退出治理 −8% 止损/周调仓）下的实际实现收益**；entry 类取 base 首次实现路径（首笔卖出）截止认定；exit 类取同仓位两条实现路径之差（严格反事实）。
- **20 日最大涨幅永久降级为参考上界**，仅作区间 [实现口径, 上界口径] 并报，红线判定、否决线、净账只认实现口径。（实证锚点：ARMUSDT +63.3%→+11.9%，旧口径高估 2.7 倍。）
- 时间口径统一：让渡按全窗累计 pp 报告，净账按年化 pp 报告，任何「省 X 换 Y」表述必须同窗。
- 失效边界（多头 T1 保留）：出现可验证的实现路径数据缺失时，允许降级为区间估计（实现收益 ± 残差），**不允许回到最大涨幅**。

**1.3 5% 红线分母（空头席提案，冻结）**：
- 单笔级筛选分母 = **决策日 T 组合 NAV 的 5%**（事前可知量，T 日可算，不依赖任何后续实现）。命中集合 T 日锁定。
- **循环论证禁令**：禁止用 base 事后实现收益定义大肉、再用大肉成本论证 base 路径该不该被治理；禁止对事后实现结果条件化筛选（miss_pct>5% 类事后筛选废除）。
- 组合层审计指标：让渡合计 / 全窗策略总收益，**仅作报告参考，不作筛选分母**（技术席条款降格采纳入书）。

## 第二章 馈赠剔除审计（对称纪律，冻结）

**2.1 神圣清单准入审计**：候选大肉笔逐笔过 LOTO（leave-one-trade-out 封禁重跑）。**单笔贡献占该笔收益主体且属月度馈赠型（MVLLUSDT 型：单笔/单月集中、剔除后翻负或腰斩）者，不得计入神圣大肉清单。** 否则「大肉神圣不可侵犯」异化为「运气神圣不可侵犯」，把校验二证伪的优势用红线重新锁死——离谱论证，零容忍。

**2.2 对称性（多头 T3 + 空头席，冻结为常设纪律）**：
- 任何「治理造成损失」的结论同过 LOTO；单笔馈赠可否决优势，单笔灾难必须可否决劣势。对称纪律不分敌我。
- 凡进入放行/否决决策的优势或代价数字，必须过同一套组合：**LTO + LMO + 月块 bootstrap CI + 段归因（如适用）**。两侧均单点主导 → 双双降权，放行仍需正证据；仅一侧主导 → 只降权该侧。对称跑完前证据等级一律记「单边检验，待对称复核」。
- 小样本判据（多头 T4 采纳）：月块数 <12（现 7 个月块）时，bootstrap P 值与 LMO **不得作独立否决项**，只报置信区间；「剔最好月翻负即 FAIL」的判据废除——治理类改动改按 3.1 双轨门槛判。

**2.3 补回认定（技术席 10 日窗升格 + 空头席 K 日补回率）**：
- 错过事件后 **10 个交易日内**治理档回补入场 → 计 `entry_deferred`，顺延成本 = 入场溢价，**不计入大肉损失**；
- 10 日外补回：旧错过事件按 base 首次实现路径截止认定，新补回**另立事件**，禁止跨生命周期累计（同一票同一波行情不得在「错过」「补回」两侧重复记账）；
- 补回率 =（K 日内治理档最终入场所捕获的 base 实现收益）/（base 实现收益），**K=20/60 两档并报分布**；仅补回率≈0 的笔计「永久错过」，报告分布而非单点。

## 第三章 验收双轨与终审表（T2，冻结）

**3.1 双轨验收（治理类改动常设框架）**：
- 收益轨：净年化差 + LOTO 封禁重跑（单笔主导 ≥50% → 收益主张撤回）；
- 风险轨：MDD、费拖累、换手（三项均不依赖馈赠，可独立成立）；
- 判据：**收益中性（|Δ年化| ≤5pp）且 MDD 改善 ≥10pp → 判「保留为风险治理工具」**，按风险轨验收，不得单轨 FAIL；
- 失效边界：≥2 年全窗复检 MDD 改善回到 base ±3pp 内 → 双轨保护失效，治理退场。
- 本条不翻案：AB 现档 −7.97pp/年不满足收益中性，不借道入箱。

**3.3 否决线双轨（承 R5 终裁一，冻结）**：
- 轨 1（闸类：直接砍既有持仓/信号）：厚利桶 sum 降幅 >5% 一票否决，分母按 1.3（决策日 NAV 5% 命中集合）；
