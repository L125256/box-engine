- 视角：机会成本。每一分工程预算花在 A 上，就是没花在 B 上；每一分保费今天实付，保护收益未来打折。

## 一、A′ 复议路径关闭后，治理路线在 F1 上还有活路吗

**判定：出场侧参数化治理（A′ 类）复议路径确认关闭；治理路线在 F1 上仍有活路，但形态不是"上线闸"，而是"监控回路"。下一主张：接受 base 裸奔 + 监控四件套作为 F1 上线形态，箱体线 bk 腿转研究轨、不与 F1 上线绑定。**

论证（机会成本视角）：

1. **R7-1 的全灭不是参数没调好，是判据空间被证明为空集。** 单自由度 T 旋钮下保费与主窗 MDD 改善同轴同向联动、无内点（S100 系列全程 ≤+1.3pp，判据线 ≥3pp 差一半以上；T=3 反转恶化；S50 等效半仓 A 且宽限期保留下跌敞口，MDD 反而更差）。再投一轮 R 周期扫 T/S 邻域，先验期望为零——这笔预算的机会成本是负的。
2. **保费今天实付，保护未来打折。** A_confirm2 口径保费 63~64pp 是全窗实付；换来的 MDD 保护在训练窗为负改善（-2.68pp），只在留出窗兑现。上线时点我们手里只有训练窗的"保护不可证实"和确定的保费账单——这正是"做到当下最好、未来打折"的反面教材。
3. **base 裸奔不是放弃治理，是把治理从"事前闸"降级为"事后监控"。** base 在四列里训练年化最高（39.24%/30.23%）、费拖累口径清晰（R7-3 定权 4.39pp/年 vs 治理档 2.91pp/年，费差仅 1.48pp/年——治理省的费不足以覆盖其保费量级的零头）。监控四件套持有人工复核触点，成本≈0，不产生路径依赖残差（R7-1 显示 entry 侧 Δ 残差 2.87/9.31pp 是纯路径依赖，机制上修不掉）。
4. **为何不主张转向 bk 腿：** bk 是另一条策略线，无 R7 系证据，转过去等于用"未标定的线"替换"已标定但治理失败的线"，重启整个标定-审计循环，上线时点后移。正确姿势是 bk 腿走研究轨并行推进，F1 上线不被其阻塞。

**失效边界（base+监控形态的退场条件，任一触发即重开 A′ 或紧急评审）：**
- 实盘滚动窗 MDD 突破 base 留出窗最差值（约 -32%）持续 N=20 交易日；
- 监控反事实账本累计显示"若挂治理本可避免的已实现损失"超过 40pp 保费当量（与原 criterion 同量级），即市场结构已从"确认延迟受罚型"翻转为"确认延迟受奖型"；
- 弱市信号触发频次显著超出历史密度（2024-2026 回放约每 2.7 年个位数 episode），说明 regime 分布外移，base 的历史优势外推失效。

## 二、10% 预算闸推广为全治理工单通用保险丝：支持还是过度工程

**判定：支持推广机制类（滚动预算窗保险丝），反对无附加条件地直接铺开。这不是过度工程——是一个成本≈0、尾部保护为真的非对称下注——但通用化前必须补两件小事。**

论证：

1. **成本-收益不对称性成立。** 闸的运行成本是一个 60 交易日滚动求和；收益端 18 组重放零误伤，AB_cap2·full144 净拦回 0.464（年化 +9.84pp），且机制上只对"持续失血时段"收紧（负让渡不耗预算、不触闸），不碰治理做对的时段。静态 5% 单笔红线历史仅 1 笔命中、防不了累积侵蚀——保险丝类型本身是缺位的，不是冗余的。
2. **但通用化前必须补两件：**
   - **同日排序缺陷修复**：R7-2 已暴露降序入账让大笔（MUU 12.3%）贴线通过、小笔反被拦——通用化后每个工单继承这个缺陷等于把闸架空。改同日聚合后一次性判定，或按让渡额升序入账，二选一，写进闸的标准规格。
   - **一阶外推 → 全重仿真确认**：当前结论不含二阶反馈（挂起改变后续事件序列）。作为"通用保险丝"写进所有治理工单的标准件前，至少在代表档上做一次引擎内嵌全重仿真，否则是在给所有工单装一个只做过一阶标定的断路器。
3. **反对意见的预答（为什么不是过度工程）**：10% 档在 A_confirm2 现役候选上只触发 2 笔/2.7 年、年化 +2.99pp、MDD 不受损——它平时沉默、只在失血时动作，这正是保险丝的定义而非过度工程的定义。真正过度的做法是给无治理动作的工单（如 base 形态）也挂闸——闸在无治理事件时是空转的，那一类不挂。

**失效边界：** 阈值 10% 标定自单一 seed、2.7 年窗口，且 15%/20% 档近乎不绑定——本质上是"10% 恰好骑在历史让渡分布的 P99 附近"。若未来让渡簇密度或单笔规模分布外移（如出现单笔 >10%·NAV 的新事件类型），10% 档要么漏拦要么常态触发变形为"慢一拍的 base"，此时须重标定而非调参续命。

## 三、MUU/SNDK/AMA 三笔 exit 处分价差：闸的问题还是行情的问题

**判定：主体是「2026-02 类特定行情的问题」（相关性崩跌日对任何延迟退出的系统性惩罚），闸的结构只是该惩罚的显性化通道；但"多日期散布"的次要成分（AMA@2026-06、SNDK@2025-11）表明这是可复现的行情类型，不是孤立事件。**

依据类型（三层证据，按强度排序）：

1. **账本内双向对照（最强证据）**：同一组合同一池，T1_S100/old131 exit 回补 45.39pp（治理卖得更高的笔），让渡仅 17.27pp——闸不是系统性卖差，是条件性的。让渡集中在单调下跌段（确认等待期内价格续跌），回补集中在震荡/V 型段（确认等待换来更高卖点）。价差方向由行情路径决定，不由闸的有无决定。
2. **跨日期散布 + 单日聚集结构（次强证据）**：top 让渡事件横跨 2024-08、2025-01、2025-11、2026-02、2026-06 五个时段——排除"单日偶然"；但最大簇是 2026-02-03 同日四标的（MUU/SNDK/BE/KORU），高相关崩跌日一字排开。这类日子里任何带确认延迟的治理（哪怕 T=1）都必然比裸 base 便宜卖——机械事实，非实现瑕疵。
3. **单自由度排除法（结构性证据）**：T=1（延迟最小档）仍让渡 17pp，且此时 MDD 改善只剩 +0.7pp——说明让渡主体不随闸松紧线性消失，是行情类型固有的。闸能修的是"卖多慢"，修不了"这类日子延迟即亏"。

**契合市场视角的推论：** 这类行情里任何治理都会失血——正确，且这正是治理路线失败的根因：为不可预知的行情类型预付保费，而保费恰在最需要保护的那类日子集中计提、保护效果却在训练窗不可证实。

**失效边界：** 若未来回放/实盘让渡分布发生翻转（回补持续 > 让渡，即震荡/V 型占比上升），同一套闸从"失血通道"变"增益通道"，届时 R7-1 的判据空间不再是空集，A′ 类复议有理由重开。判据：双向净账连续两个滚动窗 >0 且主窗 MDD 改善 ≥3pp。

## 四、给主管席的三条要点

1. **F1 上线形态定 base 裸奔 + 监控四件套**：出场侧单自由度治理已被 R7-1 证明无内点，别再投 R 周期扫参数；治理降级为监控回路，设三条退场触发线（MDD 破 -32% / 反事实失血超 40pp 保费当量 / 信号频次外移）。bk 腿走研究轨，不阻塞上线。
2. **10% 预算闸批准为治理工单标准保险丝，附两个前置**：同日聚合判定（修降序贴线缺陷）+ 代表档全重仿真（补二阶反馈）。成本≈0、历史零误伤、平时沉默——是保险丝不是过度工程；base 形态工单不挂（空转）。
3. **残余让渡定性为行情类型问题、非实现瑕疵**：MUU/SNDK/AMA 价差主体来自高相关崩跌日对任何延迟退出的机械惩罚，账本双向数据（回补 45-55pp）证明闸本身条件中性。结论写进归因底稿：这类失血不可被出场侧参数化修复，只能被"不预付保费"规避——即第 1 条。
