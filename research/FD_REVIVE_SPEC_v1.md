## §1 研究问题（一句话）

fd 入场信号（V-FD-A：滚动 Donchian N=15 / lo≤L+0.2×rng / close>L / refresh 重置 / eff=L−0.3×ATR14 / risk≤8%，**一行不动**）在更换出场规则后，能否通过全套判线复活？

fd 富矿已证（筛选段 673 笔 +723.64R、厚利 r≥8 118 笔 2019.76R、分年不翻脸、LOTO 0 败），死因集中于出场结构对回吐的暴露（realC −265.13R + q05<0）。本单只审「出场」这一个自由度。

## §2 两方向冻结（K5 语义逐字承继，禁止第三方向）

### D-A「分批止盈+保本」（=K5-fd-exit-partial3r-breakeven，batch3_run.py L844–882 逐字）

1. 入场：与冻结臂逐字相同（scan_fd_exit 路径），ep=入场收盘，eff=L−0.3×ATR14，风险单位 R≡(ep−eff)；
2. 分批触发：**收盘判定** `close ≥ ep + 3.0×R`（分批比例=50% 出半，触发阈值=+3R，均单值冻结非网格）；
3. 成交口径：触发收盘价成交；若该 bar low≤价≤high 不成立则顺延至下一满足 bar 的 open（common_fdbrk.v2_exit 谱系）；费 FEE=0.03%/bar 按持仓 bar 数逐半仓计；
4. 余仓处理：**eff 一次性上移至保本（eff2=ep）**——只上移一次、非跟踪；
5. 余仓出场三条件（收盘判定，先到先出）：close≤eff2（保本止损）/ close≥tp（止盈）/ i−ei≥30（硬顶 30bar 不变）；tp=ep+**3.5669×ATR14(入场日)**，入场时冻结；
6. 记账：r = 0.5×r₁(半仓) + 0.5×r₂(余仓)。

### D-B「放宽时间上限」（=K5-fd-exit-time45）

1. 与冻结臂唯一差异：hardcap **30bar→45bar**，其余（tp=ep+3.5669×ATR14、eff、费、入场、refresh 语义）逐字不动；
2. 对照语义明示：**「原版 30bar 硬顶」= 对照臂（ctrl）**，D-B 只改时间上限一个参数，不改 tp、不改止损结构。

### 预注册语义明示：固定 vs 跟踪（K5-atr 教训防再漂移）

- **本规格两方向的止盈目标均为入场时确定的静态固定目标（ATR 目标按入场日 ATR14 冻结），全程无任何跟踪止损 / 移动止盈 / 动态目标语义**；
- D-A 的「保本」是止损位一次性上移至 ep，**不是**跟踪止盈——三者（固定目标 / 保本上移 / 跟踪出场）在本规格中互斥，跟踪语义属未预注册自由度，测了即违例；
- K5-atr2/atr3 曾因「固定目标非动态跟踪」需事后对拍说明（【_OPS】），本条即为该教训的预注册封堵。

## §3 判线替代设计（本规格最大难点，研究主管负责设计并论证）

### 3.0 realC 为何不可再用

fd 原版判死依赖 realC（2026-06-01→2026-10-18）终验一次、验后即烧（FDBRK §C 烧毁声明；MINE_SPEC §六批次纪律：K3/K5 的 realC 数字只作图谱记账引用）。任何以 realC 复验为判线的方案均已失去「真样本外」资格，**结构性不可用**。

### 3.1 替代判线五件套（缺一即判死，不因缺 realC 豁免任何一件）

| # | 组件 | 口径 |
|---|---|---|
| ① | **realA 全窗主判** | 筛选段（et∈2025-06-01→2026-05-31）内，新出场臂 vs 对照臂**同信号配对差值**的 mean/pf/thick 分年全跑；主判对象=ΔR 不是绝对 R |
| ② | **realB 对照段** | 主窗前历史段（→2025-05-31）Δ 方向一致性门（只作同向门，不设显著性要求，样本薄如实标注） |
| ③ | **LOTO + bootstrap B=2000** | LOTO：144 池去一票重建（严格池重建+idx 牛闸重建）后配对 Δ 全过；bootstrap：对 Δ 日序列做日块 stationary bootstrap（块长 10，**B=2000**，seed=42），q05(Δ sumR)>0——较原判死线 B=1000 加倍 |
| ④ | **前瞻影子期 n≥20** | 影子窗自快照尾日次日（当前=2026-10-19）起，与 FR-1 同源挂点（SHADOW_SPEC SH-1 同款：判定轮后追加只读+旁路落盘采集）；**n≥20 配对前瞻信号必经判读，判读一次封印 sealed=true**；不因 realC 已烧而豁免 |
| ⑤ | **同窗对照臂增量归因** | 对照臂=原版出场（K5-fd-exit-ctrl 逐字），与两方向臂在完全相同信号、相同快照、相同费率下同跑；判线只认 Δ（新出场−原出场），绝对 R 仅记账 |

### 3.2 配对规则（预注册，禁跑数后改口径）

- 配对键 = **(tkr, 入场日 et) 精确匹配**。因出场差异改变持仓期→后续可入场信号集两臂不完全相同（K5 实测 n：ctrl 3604 / breakeven 3632 / time45 3500），故主判只认配对子集 ΔR；
- **配对率门：主判有效前提=配对率≥85%**（预期>95%）；低于 85% 判「规格执行异常」，停机重查，禁静默换口径；
- 未配对交易双方各自单列记账不入判线；全样本（含未配对）绝对 sumR 差作次要记账列。

### 3.3 研究主管论证：为什么这套能替代 realC 的防过拟合强度

1. **对选择偏差的压制**：本单方向数=2（终裁④冻结），参数全部单值冻结无网格；判线对象是同信号配对 Δ，牛闸、年份、市场态、入场噪声等共同因子在差值中一阶消去——realC 防的是「在已看过的数据上挑参数」，本方案防的是「挑参数空间本身」（2 个预注册方向 × 0 个自由参数）；
2. **对窗内过拟合的压制**：bootstrap 判线家族已被证明够苛——原臂在更强基数（sum_r +2125.96R）下 q05 仍 −219.54 被判死；本方案对 Δ 序列要求 q05>0 且 B 加倍至 2000，对「增量下尾」的要求严于原判线对绝对值的要求；
3. **对时间外推的压制**：realC 的真样本外功能由前瞻影子期承继——n≥20 必经、判读一次封印、方向维持门，承继 SHADOW_SPEC 全套防漂移纪律；
4. **诚实折扣（必须随结论携带）**：realA/realB 数字 K5 已看过（数据已存在），窗内主判不是真样本外，替代方案强度**严格小于** realC 一次成活。故本规格达标结论表述为「**fd 出场结构增量成立，转影子候选**」，**不等于 fd 复活上线**；放行仍走部署三道门+新预注册（R10 红线永不重开），折扣在每份报告首行标注。

## §4 判线数字（预注册冻结，一次成活，无中间态）

主判对象：配对差值 ΔR（D-A、D-B 各自独立成案，互不合并、互不择优）。

**达标 = 以下五条全部满足：**

| # | 判线 | 冻结数字 |
|---|---|---|
| J1 | 增量主判（realA 配对） | Δ meanR > 0 **且** 日块 stationary bootstrap（块长10，B=2000，seed=42）q05(Δ sumR) > 0 |
| J2 | realB 对照段 | Δ meanR > 0（同向门） |
| J3 | 分年不翻脸 | realA+realB 窗内各自然年（2024/2025/2026）Δ sumR 均 > 0（任一年 ≤0 即翻脸） |
| J4 | LOTO | 144 去一票配对 Δ meanR 全 >0；thick 去一（fd 锚 thick 118 票谱系）同步全 >0 |
| J5 | 影子期 | n≥20 配对前瞻信号，Δ meanR > 0（判读一次封印；n<20 只累计不判） |

**判死 = J1–J5 任一不满足**（含：Δ≤0、分年翻脸、LOTO 败、影子期 Δ≤0、配对率<85% 且重查后仍异常）。判死即维持 fd 原判死结论，归档为研究证据。

- **无中间态**：无「降级」「部分达标」「接近达标」等表述资格；
- **复活条件预写**：判死后唯一合法复活路径 = (a) 影子窗样本自然滚动累计至 n≥20，按本规格同判线机械复判（每自然季至多一次）；或 (b) 用户批准 v2 新预注册新预算。禁以任何「差一点」叙述复活。
