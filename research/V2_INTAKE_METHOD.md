# V2_INTAKE_METHOD · PD-AI 因子库接入方法书（预注册）

> - 版本：v1.0 ｜ 起草：交易分析团队（单 agent 10 席位，首席策略官·何执舟终裁）｜ 2026-10-20
> - 上游依据：`research/MINE_SPEC_v1.md`（86 预算与分域方案，冻结）、`research/wo_mine/CAMPAIGN_VERDICT.md`（v2 优先级定版：**Q4 缺口族 > Q1 位置族（牛躁）> Q3 反转族（弱躁）**，其次为三族之外的新族）
> - 适用纪律：R1 一发验证 / R2 知识霸权（引用必附出处）/ R4 庸医禁令 / R5 抢救义务 / R7 诚实标注 / R9 火力全开
> - **总原则（一句话）**：PD-AI 给的是「假设与公式」，不是「结论与数字」——**全程外部回测数字零采信**，一切生死由我们灶（我们引擎）、我们食材（144 池 OHLCV 日线）、六腿判线（MINE_SPEC §5.2 C1–C6）重检后裁定。
> - 本方法书不跑任何回测、不预注册任何新变体预算；新预算在预筛通过并登记 v2 候选清单后，由 MINE_SPEC_v2 预注册、**用户届时批准**方可冻结。

## 一、拿什么（交付物清单——向 PD-AI 要的具体细化，逐项可勾选）

### 1.1 因子候选交付物模板（每因子 7 字段，缺一即退回补件）

按优先级提交：**Q4 缺口族 > Q1 位置族 > Q3 反转族 > 其他新族**（CAMPAIGN_VERDICT 下一程路线第 3 条定版）。

| # | 字段 | 要求 | 勾选 |
|---|---|---|---|
| ① | **因子名与一句话金融含义** | 名称可检索；含义须说清「为什么这个量可能预测收益」（机制一句话，不许只说「历史上有效」） | ☐ |
| ② | **公式（伪代码级）** | 输入字段 / 窗口 / 参数 / 归一化四要素齐备。例：`gap_ret = open_t / close_{t-1} - 1`，窗口 N=20，横截面分位归一化，参数表全列出。**伪代码级=照抄即可在我们引擎复算**，不接受「详见代码」 | ☐ |
| ③ | **原始出处** | 研报引用（机构+标题+年份）/ 大赛届次 / 作者。R2 知识霸权：出处缺失按「未验证假设」降级标记 | ☐ |
| ④ | **数据需求（字段清单）** | 逐字段列明：OHLCV？复权口径？基本面字段？横截面宽度要求（需多少只股票同时可比）？高频/日内数据？**任何非 OHLCV 日线依赖当场标注**（触发闸①预判） | ☐ |
| ⑤ | **适用市场与周期声明** | 原作者适用市场（A 股/美股/加密）、适用周期（日/周/分钟）、是否声明了失效条件 | ☐ |
| ⑥ | **原作者回测口径摘要（仅 metadata）** | 样本期 / 持有期 / 费用假设 / 池宽度 / 报告的 IC 或收益数字——**全部仅作参考 metadata 登记，数字零采信**，不进入任何判线 | ☐ |
| ⑦ | **未来函数自检声明（因子工程师预检）** | 提交方须声明：公式中是否含 `t` 日之后信息（收盘后才能算的量被用于 t 日开盘？横截面归一化是否用了全样本分位？）。声明+自查过程一并交付 | ☐ |

### 1.2 不接收清单（收到即退，不进入登记）

1. **裸回测数字**：只给「年化 X%、夏普 Y」无公式的——退；
2. **黑盒代码**：无伪代码公式、仅可执行代码且依赖不可审计环境的——退；
3. **数据需求我们无法满足**：依赖非 OHLCV 日线（资金费/基本面/高频分笔/境外跨市场）的因子——退，按 R5 登记为【数据受限·非死】挂账（对齐 RG3 先例），复活条件=数据回填工单；
4. **打包交付**：一个文件塞几十个因子无逐因子 7 字段——退回按模板逐因子补件。

## 二、怎么过滤（预筛三道闸，全部通过才入 v2 候选清单）

### 闸① 数据可行性闸——144 池 OHLCV（日线）能否喂出来

逐字段比对清单（输入字段 × 我们数据）：

| 交付物声明的字段 | 我们有无 | 判定 |
|---|---|---|
| Open / High / Low / Close / Volume（日线，144 池 + idx） | 有【实证：144 池现行引擎口径】 | ✅ 通过 |
| 复权因子 / 前后复权价 | 有（现行引擎口径） | ✅ 通过 |
| 换手率代理（成分变动率，RG2 口径） | 有代理口径 | ✅ 通过（须用代理实现） |
| breadth（calc_breadth，22.92/33/144 锚） | 有【实证：2026-10-19 实测】 | ✅ 通过 |
| 资金费率 | **无**（RG3 不可判定·挂 RC-数据） | ❌ 数据受限退 |
| 基本面（财报/盈利/市值结构） | 无 | ❌ 退（挂账非死） |
| 日内/分笔高频 | 无 | ❌ 退 |
| 境外市场/跨市场联动数据 | 无 | ❌ 退 |
| 横截面宽度 >144 | 不满足（144 池定版禁扩容，R7） | ⚠️ 需作者方案在 ≤144 宽度下仍成立，否则退 |

### 闸② 口径闸——日线级 / 可 lag1 防前视 / 无跨市场依赖

1. **日线级**：因子可用日频 OHLCV 完整复算，无需 tick；
2. **可 lag1 防前视**：因子值在 t-1 收盘后可得、用于 t 日决策不引入未来信息（对齐域标签 shift(1) 纪律，MINE_SPEC §2.4）；横截面归一化须用滚动窗/时点分位，禁全样本分位；
3. **无跨市场依赖**：不依赖境外市场同时刻数据、不依赖资金费；
4. **R10 红线预检**：若该因子本质是「状态变量→部署开关」类（T2/G1/G2/W2 三条判线轴已死域），直接标记「判线轴撞车」退回——v2 只收「选股因子/事件统计/图谱记账」类。

### 闸③ 新颖性闸——与已判死 35 态清单 + 86 变体不重复（对照表预建）

逐项对照（对照表随首件交付预建，R2 出处）：

| 对照库 | 出处 | 查重要点 |
|---|---|---|
| 35 态 FDR 清单（26 死+7 不可判定+1 样本不足） | `research/wo_g1g2fdr/G1G2FDR_REPORT.md` §3 | 同公式/同窗口/同归一化=重复；唯一幸存 F6\|lo 已入 dual 衰减态，禁碰防口径混写 |
| 86 变体全表（Q1–Q6+K1–K5） | `research/wo_mine/FDR_MERGED_M86.jsonl` + FACTBOOK 三批 jsonl | 同族同参=重复；同族换参须论证「参数不是 p-hacking 挑的」 |
| ATLAS 392 格图谱 | `research/wo_mine/ATLAS_v1.json` | 候选须声明目标域；目标格已是「胜任」或「无效」的须给差异化论证 |
| REGIME 13 死 + 资金费箱体 bk + 箱体 brk | `research/wo_regime/REGIME_REPORT.md`、W1 台账、FDBRK_REPORT | 提前性判线类退；资金费类退 |
| R9 排除册 | 各战报排除册节 | 排除册登记的候选（如空头镜像）不算新族，走原承接通道不占 v2 新预算 |

**查重判定**：公式等价（代数等价或仅参数微调且无独立机制论证）= 重复，退；机制不同但输入重叠，放行入清单并标注「与 X 变体相关，重检时须报相关性」。

## 三、拿到后怎么处理（流程管线，七步不可跳）

```
[PD-AI 交付] → S1 登记 v2 候选清单（JSONL）→ S2 预筛三道闸 → S3 MINE_SPEC_v2 预注册
→ S4 用户批准（新预算冻结）→ S5 独立重检（我们灶/我们食材/六腿判线）→ S6 达标进影子期
→ S7 影子期 n≥20 前瞻 → 图谱/手册入册
```

- **S1 登记**：每因子一行 JSONL（`wo_mine/v2_candidates.jsonl`），字段=交付物模板 7 字段 + 提交批次 + 查重结论；
- **S2 三道闸**：闸①②③逐项留痕，任一不过=退件或【数据受限】挂账，不进清单；
- **S3 预注册**：通过者编入 MINE_SPEC_v2（族归属按 CAMPAIGN_VERDICT 优先级：Q4 缺口扩展 / Q1 位置牛躁域 / Q3 反转弱躁域 / 新族单列）；**变体预算由用户届时批准后冻结**，冻结后加一格=整族无效（R1，对齐 v1 先例）；
- **S4 用户批准**：预注册文件交用户过目放行，未批准不开工；
- **S5 独立重检**：只跑我们引擎（我们灶）、只用 144 池日线（我们食材）、只认六腿判线 C1–C6（含 C6 合并 FDR——v2 变体与 v1 未消化项**同表合并**，禁止分批放宽，MINE_SPEC §5.2 先例）；分域口径沿用 D1 四域+D3 安慰剂；PD-AI 的 ⑥ 字段数字全程零采信、不进任何判线；
- **S6 影子期**：域胜任格（C2+C4+C6 过且 C1/C3 不劣、双池同向）进影子候选，n≥20 前瞻 FR 同源；「域胜任但全窗不稳」按 dual 衰减态先例处置，无中间态放行；
- **S7 入册**：死活均入 FACTBOOK v2（正负事实同权，R9——「不要只做否定报告」对 PD-AI 接入同样适用：每个接入因子无论生死必须产出其分域事实行）。

**纪律伴行**：判死必须附专属复活条件（R4/R5）；【数据受限】≠死（R5）；任何「PD-AI 说它有效」不得出现在我方报告的结论句里，只能出现在 metadata（R7）；部署通道三道门不变、R10 红线永不重开。

## 附：给用户的接入操作指引（白话）

### A.1 您接入 PD-AI 专家团后，第一句话照抄这个模板

> 「我们是量化研究方，现征集因子候选。请按以下模板**逐因子**交付，共 7 项：①因子名+一句话金融含义；②伪代码公式（输入字段/窗口/参数/归一化，照抄可复算）；③原始出处（研报/大赛届次/作者）；④数据需求字段清单；⑤适用市场与周期；⑥原作者回测口径摘要（我们仅作参考，数字不采信）；⑦未来函数自检声明。**优先提交缺口类、价格位置类、短期反转类因子**。请勿只发回测数字或黑盒代码。」

### A.2 怎么给到我们

- 直接**粘贴对话**或发文档均可；多个因子请逐个分节，不要打包一段话；
- 公式部分请让他们写伪代码或 Excel 公式级描述，「代码附件」我们不看；
- 我们收件后会给您一份「收件回执」：每个因子标【进入预筛】/【退件（原因）】/【数据受限挂账】。

### A.3 预期来回几轮

- **第 1 轮**：您把模板发给 PD-AI，收回第一批交付物 → 转给我们；
- **第 2 轮**：我们预筛后给退件清单，您把「缺哪个字段」反馈给 PD-AI 补件（通常 1–2 个来回补齐）；
- **第 3 轮**：通过三道闸的因子进 v2 候选清单 → 我们出 MINE_SPEC_v2 预注册（新变体预算清单）→ **您批准预算后**我们才开跑重检；
- 之后每批重检收口交战报（死活均报，附事实手册行）。

### A.4 三句话记住分工

1. **他们出假设，我们出判决**——PD-AI 的任何回测数字我们一律重算；
2. **先过闸再花钱**——数据不可行/口径有前视/炒冷饭的因子在预筛就拦下，不进预算；
3. **预算您批**——v2 测几个变体由您在预注册文件上批准后冻结，我们不会偷偷多测。
