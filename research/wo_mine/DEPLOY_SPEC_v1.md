## 2. 仓位折扣算法（公式级，档位冻结）

### 2.1 公式

```
格子实际仓位 = 增强基线仓位 × 折扣档位系数
增强基线仓位 = 每格 0.5%（账户总权益名义，冻结）
增强层总敞口上限 = 2.0%（4 活格 × 0.5% 满档上限；S4 灰态不占）
折扣分母 = 账户总权益（独立于 F1 的 12.5% 敞口；两层数学不相加进任何熔断阈值计算）
```

### 2.2 折扣档位表（新增预注册数字，批准即冻结；判线数字全部承继 SHADOW_SPEC/J5 冻结值，零新判线）

| 档 | 系数 | 进入条件（承继冻结判线） | 退出条件 |
|---|---|---|---|
| T0 观察档 | **25%** | 登记即部署起点；n<10 | n≥10 无早死信号 → T1 |
| T1 试运行档 | **50%** | n≥10 且早死判据未触发 | n≥20 判读：达标→T2；命中率<60% 但 t≥2 且 IC>0→T3；判死→T4 |
| T2 转正档 | **100%** | n≥20 三腿达标（IC>0 ∧ t≥2 ∧ 命中率≥60%；S5：Δ meanR>0；S4：事件三腿） | 后续季度复判失败→T4（S5 复判≤1/季） |
| T3 降档 | **25%** | n≥20 时 IC>0 ∧ t≥2 但方向命中率<60%（主腿过、辅助腿弱） | 下一复审窗（季度）重读一次 |
| T4 下线 | **0%** | 早死线触发（n≥10 ∧ t≤−2 ∧ IC 均值<0）或 n≥20 判死（IC<0 / S5 Δ≤0 / S4 事件腿翻） | 仅季度机械复判（同判线）可复活，复活后回 T0 |

- S4 专属：SUSPENDED 期=灰态不部署；ACTIVE 后按事件格判线走同表（事件≥3 次判读）。
- 单池封顶注（新增预注册）：S1–S3 为 full144 单池格，**T2 上限按 50% 执行**（=T1 系数封顶）；双池同向复核通过后（old131 重判入图谱且同向）方可解锁 100%。定依据：单池证据=一半证据，折扣系数取其半，诚实折扣。

### 2.3 档位数字定依据（R7 强制标注）

- 60% / t≥2 / n=20 / n=10 / Δ meanR>0：全部为 SHADOW_SPEC_v1 §3 与 FD_REVIVE_SPEC J5 **冻结数字逐字承继**，非本单新造。
- 25%/50%/100% 三档系数：新增预注册。依据：①增强层是新资金风险，上限设计为 F1 主敞口（12.5%）的零头，最坏情形（4 格满档）总敞口 14.5%，单格最坏亏损受 −8% 同款止损纪律约束时对净账冲击 ≤0.4%——在 CB1 红线（−8%）噪声以下；②三档离散而非连续调节，杜绝逐日调仓的过拟合空间与换手成本；③25%=「有回测证据、无前瞻证据」的诚实起点，50%=「前瞻进行中未失败」，100%=「前瞻终审达标」，与证据强度单调对应。

### 2.4 架构定性：F1 外增强插件层（推荐+理由）

**推荐：F1 之外的增强插件层，仓位独立小仓（0.5%/格，总 ≤2%），绝不进 F1 权重。**

理由（四条）：
1. **台账权威不可污染**：F1 台账口径是「买什么」唯一权威，f1_signal.py 引擎 sha256 锚定、参数全表锁定；若折扣进 F1 权重，等于每次影子读数变动都改主引擎行为 = 变相 R10 回写，且敞口变动触发 §一.12「阈值随敞口走」的熔断重标定连锁——工程与治理双灾难。
2. **熔断阈值数学独立**：CB1/CB2/费线全部按 12.5% 敞口标定（R13），混入增强层敞口即刻度失真（§一.12 口径警告逐字）。独立小仓使两层回撤互不串账。
3. **失败可整体摘除**：T4 下线=插件归零，F1 主引擎零感知；反向若增强层爆雷也不触发主引擎熔断误动作。
4. **语义清晰可解释**：用户问「卡片能买吗」时答案干净——F1 榜单是主菜（12.5%），分域增强是独立小菜（≤2%），互不背书（承继 §7.6 两引擎互不背书先例）。

### 2.5 与 F1 的三条联动纪律（增强层单向让位）

1. F1 regime 闸关（on_holdcash=true）→ 增强层**整体冻结开新仓**（存量按各自规则退出）；
2. F1 breakers.overall=red → 增强层**整体冻结**（新仓+调仓均停）；
3. F1 崩市日 → 增强层次日同步清仓。三条均为单向让位：增强层状态**永不**反向影响 F1。
4. F1 CB2 冻结期增强层**不连带冻结**（增强层有独立小止损 −8% 同款与 T 档自降级机制，风险自含）。

