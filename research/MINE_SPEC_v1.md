## 〇、用户核心思想的合法落地形态（纲领的魂）

「不存在全模式通吃」→ **分域胜任图谱（Domain Competence Map）**：

1. 用状态变量把历史切成若干**域**（牛市域/震荡域/熊市域，或成本域等，§二）；
2. 离线评估每个候选因子/框架变体在**每个域**的胜率/收益/回撤/垫（§四）；
3. 产出「哪个域该用哪个策略」的图谱 + 全量「域×策略格」统计事实手册（§五）；
4. 图谱的**唯一合法用途**：①离线研究分层（让公式适应市场=按域匹配策略，而非让市场适合公式）；②TR 触发器辅助的**人工切换参考**（执行仍走 TR-1~5 + 人工确认）。任何「读数→仓位」自动映射禁止写入任何脚本。

**与已判死路线的根本差异（合法性根基）**：已死清单（T2 方向开关、W2 四态条件化 RS、35 态 FDR、G1/G2 门域）全部把状态变量判在「**部署开关 / 条件化 alpha IC / 触发提前性**」三条判线上；本纲领把域判在第四条线上——**域不判生死，域是评估坐标系**。判线对象是「策略×域」格子的统计事实，状态变量只提供分层标签（lag=1 防前视）。四条判线轴不重叠，故不构成炒冷饭。

## 二、分域方案（状态变量候选，≥2 套并行 + 1 套安慰剂）

### 2.1 D1 主方案：趋势×波动四域

- 轴 A（趋势）：idx vs MA50 → 牛 / 弱。idx 与 MA50 口径逐字同源引擎（f1_signal.py:638 同源，ALPHA D0-1 已证 69 切换日 diff=0）。
- 轴 B（波动）：池 vol20 中位在 realA 的 P50 → 稳 / 躁。
- 四域：**牛稳 / 牛躁 / 弱稳 / 弱躁**。
- 差异化论证：T2 死于「idx>MA50 单变量方向开关」、F3 死于「vol tercile→alpha IC 态」——本方案两轴只作分层标签，无开关语义、无 IC 腿；且 T2/F3 均为单变量，双轴交叉 2×2 在已死清单无成员。

### 2.2 D2 副方案：宽度×成本四域

- 轴 A（宽度）：breadth（calc_breadth 已上线，2026-10-19 实测 22.92/33/144 锚）在 realA 的 P33/P66 → 宽 / 中 / 窄（三档）。
- 轴 B（成本代理）：换手20（开桶日成分变动率，RG2【推断】口径）realA P50 → 低费 / 高费（二档）。
- 差异化论证：F5 宽度态死于「tercile→IC」判线；G-费档 PROXY 死于「vol20/量能作**门**的 IC<0.02」——本方案宽度只作标签、成本代理不作门不作 IC；换手作成本轴与 RG2 的「换手→变脸提前性」判线轴亦不同。
- 【数据受限登记】真实资金费域轴（RG3 复活前置）缺席：凡需资金费的域变体一律标【数据受限】挂账非死。

### 2.3 D3 安慰剂域（守恒检验，图谱合法性闸门）

- 域标签逐日随机打乱（seed=42，100 次重排）：若某变体的「域间差异」在安慰剂标签下同样频繁出现（P(安慰剂达到观测差异) > 0.05），则该变体的图谱条目标记 **MAP-INVALID**（域间差异不可归因于域）。
- **不守恒即无效**：这是「分域是否有信息」的本征检验，先于任何策略生死判断。

### 2.4 域切分方法（离线，冻结）

1. 状态变量逐日计算，分位锚（P33/P50/P66/P80）用 realA（2025-06-01→2026-10-17）冻结数值**先落盘后回放**（防切分后验）；
2. 域标签一律 **lag=1**（shift(1)，用昨日状态标今日格）；
3. 合成段（2024-01-24→2025-05-31）只作低权重佐证（R7，引用必带「合成段·低权重」）；
4. 每域最少样本门：realA 内 <60 交易日的域登记 INSUFFICIENT，不入图谱只入事实手册附数；
5. 变脸锚（REGIME 重锚【实证】：E1=2026-04-20 / E2=05-09 / E3=07-29）用作域切换日核对与分域稳健性检查，不作域定义；
6. 状态变量候选与 35 态清单逐项查重登记（研究主管 §七 签核项）：D1 双轴交叉、D2 宽×费交叉、D3 安慰剂，均非 35 态成员。

### 3.2 Q2 时序统计族（8 变体）

## 五、判线体系（预注册，先冻结后运行）

### 5.1 判线单位

「**变体 × 域**」格。每个变体在 D1 四域（+D2 副方案、D3 安慰剂）各产出一格；跨域汇总判生死，域内判胜任。

### 5.2 六腿判线（因子族与框架族通用）

| 腿 | 判线 | 说明 |
|---|---|---|
| C1 胜率 | 目标域内费后胜率 vs 同域随机带（20 种子，seed=42..61 同 ALPHA B 臂法）中位数 | 因子族=选股三臂；框架族=臂 vs base 同域 |
| C2 超额 | 目标域费后年化超额（vs 池等权同域 / base 同域）>0 且日块 stationary bootstrap 95% CI 不含 0（块长 10，B=2000，seed=42） | 核心腿 |
| C3 回撤 | 目标域内 MDD ≤ base 同域 MDD（不恶化） | — |
| C4 垫 | 域内效应量 ≥3× 随机置换基线中位数（置换 1000 次，seed=42） | 家法垫≥3× |
| C5 稳健 | LOTO（144 去一重抽 20 次 ≥19 次方向不变）+ 分年不翻脸 + lag1 全量重跑结论方向不翻转 | 对齐 W3 T2/G2 教训 |
| C6 多重检验 | BH FDR q=0.10 **合并族 m=86**（86 变体一次性登记，全纲领共用一张 FDR 表；分批运行时逐批补入同一张表，禁止分批各自放宽） | 防 p-hacking 命门 |

### 5.3 生死与胜任判定（无中间态）

- **域胜任**：某格过 C2+C4+C6（核心三腿）且 C1/C3 不劣 → 登记「该变体在 X 域胜任」入图谱与事实手册，转影子候选（n≥20 前瞻，FR 口径同源）。
- **变体成活**：≥1 个域胜任 + C5 全过 → 成活；仅域胜任而 C5 不过 → 「域胜任但全窗不稳」，登记图谱、不给部署通道（无中间态：既不判死也不放行，按 dual 衰减态先例处置）。
- **判死**：全域不过核心三腿 → 判死，报告必须附：全量逐域数字 + FDR 坐标 + **专属复活条件**（RC-数据 / RC-事件 / RC-结构 三类模板，对齐 REGIME §4.3，禁止空判）。
- D3 安慰剂不守恒 → 该变体图谱条目标 MAP-INVALID（域差异非域所致），生死判定仍按全窗数字走，两标记并行不混写。

### 5.4 分域记账纪律（R10 红线的工程化）

- 域标签 shift(1)；域内数字一律随附 n（交易日数）；n<60 的域只入事实手册不入图谱判分；
- **禁止把域内最优格直接当部署建议**——图谱产出的是「研究坐标」，任何部署走影子期+新预注册+人工确认三道门；
- 双池（old131/full144）纪律全程适用：域胜任须双池同向，单池达标=登记不放行（对齐 W3 总判定 FAIL 先例）。

### 5.5 正面产出硬指标（「不要只做否定报告」的落实）

**事实手册 FACTBOOK_v1.md 是本战役第一硬交付**，定义如下：

1. **每族每变体无论死活**，必须在手册登记其「域×指标」行：n / 费后胜率 / 年化超额 / MDD / 垫倍数 / FDR q 值 / CI——正负均入册（「RS 动量在弱躁域超额 −X pp，CI[−a,−b]」= 「该域禁用 RS」的可用事实，与正事实同权）；
2. 每批战报必须含 ≥5 条标注【实证】的「可用统计事实」摘要（规则：带 n、带 CI、带域标签、带口径出处，四者齐备才算「可用」）；
3. 手册按域组织索引（牛稳/牛躁/弱稳/弱躁 × 策略族矩阵），终版汇成分域胜任图谱 v1（热力表+每格一句话结论）；
4. 【数据受限】变体（资金费依赖）在手册单独成节挂账，复活条件统一指向 RG3 数据回填工单。
