# 批量点火 · 第一段 · 系统说明

状态：**独立策略，已上线，小仓机会型**
线上页面：https://l125256.github.io/box-engine/firstleg/
页面文件：`firstleg/index.html`；数据快照：`firstleg/build_report.json`

## 1. 一句话逻辑

不猜底，只做“当天有批量资金点火”的股票：同一天至少 3 只个股涨幅 ≥4% 且放量 2 倍、站上 MA50，才认为市场出现群体性进攻；取涨幅前 5，次日开盘各开一仓，用 2.5 ATR 止损、2.5 ATR 平半、剩余 8 ATR 封顶、20 根时间退出。

## 2. 精确规则

### 2.1 点火（收盘判定）

单只个股全部满足：

- 当日涨幅 ≥ 4%。
- 当日成交量 ≥ 20 日成交量中位数的 2 倍。
- 收盘 > MA50。
- 收盘价 ≥ 5；20 日成交额中位数 ≥ 3000 万美元；ATR% ≤ 6%。
- 只做个股：剔除 ETF 与杠杆 ETF。
- 至少 210 根历史；非数据跳变、非回填段之外的真实 bar。

### 2.2 批次门槛

- 同一天“站上 MA50 的点火”数量 ≥ 3 只，才开火。
- 不足 3 只：当天不做。这个门槛本身就是震荡/下跌过滤，不要为了“最近没单”而降低。
- 开火日按当日涨幅从高到低取前 5 只；次日开盘各开一个仓位。

### 2.3 出场

- 止损：入场价 − 2.5 × ATR。
- 第一止盈：入场价 + 2.5 × ATR，平掉一半。
- 第二止盈：入场价 + 8 × ATR，剩余全平。
- 时间退出：最多 20 根日线，按收盘平仓。
- 跳空：开盘已低于止损按开盘价成交；开盘已高于止盈按开盘价成交。
- 不设“关火/停新仓”：2026-10-28 实测 5 日停新仓把年化从 52.2% 降到 40.8%，回撤只从 12.76% 降到 11.48%，被挡掉的 35 仓 PF 1.65、逐笔 +15.9pp，是正期望，已去掉。

### 2.4 仓位与成本

- 5x 逐仓；单笔保证金 = 权益 × 3%（名义 = 权益 × 15%）。
- 最多 8 个同时持仓；总毛敞口 ≤ 2.4 × 权益。
- 成本：手续费 + 滑点 0.20% 往返；资金费 0.03%/日；5x 爆仓距离约 19%。

## 4. 当前状态与“一个月没单”的解释

- 2026-10-30：全部点火 0 只，站上 MA50 的点火 0 只，停火。
- 2026-09-01 → 10-30 共 60 根日线：只有 13 天出现任何点火，其中 12 天只有 1–2 只，未达到 3 只批次门槛；只有 2026-09-21 成批。
- 最近一次单只点火是 2026-10-15 的 MSTR（+4.7%），之后没有新点火。
- 点火自身最近一次成批是 2026-09-21；五系统合并口径最近一次实际开仓是 FD-1 在 2026-10-23 开的 META，截至 10-30 已空 7 天（不是一个月）。
- 这是“批量点火”策略的正常干旱期：没有群体性进攻就不做。降低 3 只门槛会显著改变策略性格，未获批准不要改。

## 5. 文件与运行

| 文件 | 作用 |
|---|---|
| `strategy.py` | 点火条件、批次、价位、单笔模拟、最近信号 |
| `build_page.py` | 生成 `index.html` 与 `build_report.json` |
| `backtest_versions.py` | 官方组合回测：全样本，多退出/关火变体 |
| `backtest_2026.py` | 同一引擎，只跑 2026-01-26 起真实段 |
| `backtest_versions.json` | 全样本回测结果快照 |
| `backtest_2026.json` | 2026 真实段回测结果快照 |
| `recent_ign.py` | 2026-09-01 起逐日点火家数核对 |

从仓库根目录运行：

```bash
# 页面本地重建（写 firstleg/engine/index.html）
python firstleg/engine/build_page.py
# 经明确批准后再复制到线上目录：
# cp firstleg/engine/index.html firstleg/index.html
# cp firstleg/engine/build_report.json firstleg/build_report.json

# 官方组合回测（需要 cache_fresh；也可用 V2_CACHE 指定绝对路径）
python firstleg/engine/backtest_versions.py
python firstleg/engine/backtest_2026.py

# 逐日点火核对
python firstleg/engine/recent_ign.py
```

统计口径提醒：早期用“逐信号加总”的粗扫得到过 103 仓 / 51.5% / +437% 名义和，那是**信号级**结果，不是组合级；官方页面和本 README 使用 `backtest_*.py` 的组合账本（8 仓上限、2.4x 毛敞口、次日开盘、成本与资金费），全样本为 110 仓 / 59.1% / +93.6%。两者不要混用。

## 6. 已知限制

- 只做多；市场没有群体性进攻时会长期空仓。
- 2026 段 49 仓，PF 2.17 受少数批次影响；前 3 仓占盈利 18.1%。
- 回测按日线 OHLC 近似，无法刻画盘中顺序和真实滑点。
- 资金费固定 0.03%/日，实际会变化。
- 不设关火意味着急跌期仍可能开火；这是用回撤换频率的选择，不是遗漏。

## 7. 变更纪律

- 点火阈值、批次门槛、出场参数已冻结；改任何一项必须新建变体、保留旧结果、写明前后统计。
- 未获明确批准，不覆盖 `firstleg/index.html`、不改 C1、不动云端任务。
- 不把 key/secret、token 写入仓库、页面或日志。
